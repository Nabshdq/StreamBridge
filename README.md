# StreamBridge

*Your TikTok viewers, visible on Twitch and YouTube.*

StreamBridge is a Windows desktop app that relays chat, gifts and follows from a
TikTok LIVE to Twitch chat and/or YouTube live chat. Everything runs on your own PC,
and you use your own accounts.

> **Status:** early development. There is no release yet.

## Planned features

- Read a TikTok LIVE anonymously (no TikTok login).
- Send to Twitch, YouTube, or both.
- Spam filter, gift combo merging, and per-destination message templates.
- Built-in rate limiting and YouTube quota tracking.
- English and Bahasa Indonesia interface.

## Requirements

- Windows 10 or 11.
